Avenor Optimization FAQ

Welcome to the offline Avenor Help & FAQ page. Avenor is built to run flawlessly on everything from legacy dual-core processors to modern flagships. Follow these tips to optimize your experience on resource-constrained devices.

🚀 Performance Presets

Avenor includes an automated Performance Benchmark on startup, but you can override it:

  • ECO Mode: Disables all background animations, procedural shaders, and background drawing. Use this if your phone has less than 2GB of RAM.
  • BALANCED: Enables basic UI transitions but keeps heavy graphics caching active.
  • VIVID: Full fluid animations, rotating background effects, and highest refresh rate. Recommended for 4GB+ RAM.

🧹 Clearing Background Processes

Audio processing (Equalizer, AutoMix, Crossfade) requires uninterrupted CPU time. On dual-core or heavy-load devices:

  • Clear recent apps before extended listening sessions.
  • Disable aggressive battery savers for Avenor, as they can kill the background playback service (Media3).

💾 Disk Usage & Storage

Avenor uses an embedded SQLite database (Room) for high-performance offline metadata caching.

  • The database automatically runs a VACUUM operation if it exceeds 5MB to prevent storage controller fragmentation.
  • No cloud telemetry or tracking data is stored. Your footprint stays strictly minimal.

🎛️ Equalizer & Crossfade

Our custom DSP tools are built for low-latency:

  • Crossfade: Operates completely off the main UI thread. If a CPU stall is detected (e.g., thermal throttling), it snaps to volume targets to prevent audio tearing.
  • Auto-EQ: Relies purely on ID3 tags (Offline Metadata). No network requests are made.
